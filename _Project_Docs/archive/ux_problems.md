# UX Problems

### 1. User Friction
- **Contact Reveal**: Once a user clicks "Show Phone," it's saved in the session. If they clear cookies or switch devices, they have to "pay" with a click again.
- **Profile Completion**: The gamification popup might be intrusive during frequent profile updates if not properly dismissed.

### 2. Navigation Issues
- **Category Depth**: Browsing deep hierarchical categories without breadcrumbs can leave users feeling "lost."
- **Search Feedback**: No "No results found" suggestions or autocorrect for misspelled profession names in the search bar.

### 3. Broken Interactions
- **Language Switch**: Switching languages on a filtered search page often resets the filters because the locale route doesn't always preserve query parameters.
