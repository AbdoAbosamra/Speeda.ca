# Archived documentation

These files are kept for history. **None of them is maintained.** Many
describe code that was later changed or removed, such as Livewire,
`DebugController`, `ServiceProviderProfileController`, push-over-SSH deploys,
or Tailwind. The current docs are in [`/docs`](../../docs/README.md).

- `*.md` (this folder): everything that used to be in `_Project_Docs/`.
- `root/`: reports that used to sit in the project root, including the old
  root `README.md`.
- `DEPLOY_README.md`: the old Arabic walkthrough for a generic VPS
  (`/var/www`, Supervisor). It was moved out of `deploy/`.

The two audits that were checked against the code, and that feed
`docs/CHANGELOG.md`, are `AUDIT_2026-10-09.md` and
`VERIFIED_AUDIT_2026-09-08.md`.
