## HTML CODE SNIPPETS

### Add to Every Page (After `<meta name="viewport">`)

```html
<!-- Standard Meta Tags -->
<meta name="description" content="PAGE_DESCRIPTION_HERE">
<meta name="keywords" content="keyword1, keyword2, keyword3">
<meta name="author" content="Speeda">
<meta name="robots" content="index, follow, max-image-preview:large">

<!-- Canonical Tag -->
<link rel="canonical" href="{{ url()->current() }}">

<!-- Multilingual Alternate Links -->
<link rel="alternate" hreflang="en" href="https://speeda.com?lang=en" />
<link rel="alternate" hreflang="ar" href="https://speeda.com?lang=ar" />
<link rel="alternate" hreflang="fr" href="https://speeda.com?lang=fr" />
<link rel="alternate" hreflang="x-default" href="https://speeda.com" />

<!-- Open Graph Tags (for Social Sharing) -->
<meta property="og:title" content="PAGE_TITLE_HERE">
<meta property="og:description" content="PAGE_DESCRIPTION_HERE">
<meta property="og:image" content="https://speeda.com/images/og-image.png">
<meta property="og:url" content="{{ url()->current() }}">
<meta property="og:type" content="website">
<meta property="og:site_name" content="Speeda">

<!-- Twitter Card Tags -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="PAGE_TITLE_HERE">
<meta name="twitter:description" content="PAGE_DESCRIPTION_HERE">
<meta name="twitter:image" content="https://speeda.com/images/og-image.png">
```

## TRANSLATION KEYS (For Laravel `lang/` files)

### Add to Each `lang/{locale}/[file].php`

```php
    // SEO Meta Tags
    'meta_title' => 'Page Title Here',
    'meta_description' => 'Page description here (155-160 characters)',
    'meta_keywords' => 'keyword1, keyword2, keyword3',
```

## CHARACTER COUNTS (Optimal SEO)

| Element | Recommended Length | Max Length |
|---------|-------------------|-----------|
| Title | 50-60 characters | 70 characters |
| Meta Description | 155-160 characters | 160 characters |
| Meta Keywords | 5-8 keywords | - |
| URL Slug | 50-75 characters | 100 characters |
| H1 Title | 20-70 characters | - |

## VERIFICATION TOOLS

### Online Tools to Check SEO:
1. **Google Search Console** - https://search.google.com/search-console
2. **Bing Webmaster Tools** - https://www.bing.com/webmasters
3. **SEO Audit Tool** - https://seositecheckup.com
4. **Meta Tags Inspector** - https://www.seobility.net/en/seocheck/
5. **Schema Validator** - https://schema.org/docs/schemas.html
6. **Mobile-Friendly Test** - https://search.google.com/test/mobile-friendly

### Command Line Checks:
```bash
# Check title tag
curl -s https://speeda.com | grep "<title>"

# Check meta description
curl -s https://speeda.com | grep "meta name=\"description\""

# Check all meta tags
curl -s https://speeda.com | grep "<meta"

# Check hreflang
curl -s https://speeda.com | grep "hreflang"

# Check canonical
curl -s https://speeda.com | grep "rel=\"canonical\""
```

## COMMON SEO MISTAKES TO AVOID

❌ **WRONG:**
- Duplicate meta descriptions on multiple pages
- Keyword stuffing ("plumber, plumbing, plumber service, plumbers...")
- Auto-generated descriptions that don't make sense
- Forgetting hreflang tags for multilingual sites
- No structure in Open Graph tags
- Broken canonical tags pointing to non-existent URLs

✅ **RIGHT:**
- Unique descriptions for every page
- Natural keyword usage (2-4 keywords per page)
- Human-readable, compelling descriptions
- Complete hreflang implementation
- Consistent OG tag structure
- Self-referencing canonical tags
