## 🚀 كيفية التشغيل

### تشغيل شامل:
```bash
# Windows
.\run-tests.bat

# Linux/Mac
chmod +x run-tests.sh
./run-tests.sh
```

### تشغيل محدد:
```bash
# اختبارات الأمان فقط
php artisan test tests/Feature/Security

# اختبارات الوحدة فقط  
php artisan test tests/Unit

# مع تقرير التغطية
php artisan test --coverage-html coverage
```
